# Puppeteer Render Test

An experimental testing suite for evaluating different headless browser rendering techniques using Puppeteer.

## Purpose
- **Rendering Comparison**: Test how different web components render under various Puppeteer configurations.
- **Performance Benchmarking**: Measure the speed and resource usage of headless browser rendering.
- **Debugging**: Isolate rendering issues in a controlled environment.

## Usage
- Run tests via the provided scripts in the `src` directory (if available).
