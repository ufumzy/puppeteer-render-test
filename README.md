# 🧪 Puppeteer Render Test

> An experimental testing suite for evaluating different headless browser rendering techniques and performance using Puppeteer.

---

## 🚀 Overview

This project is tailored for performance benchmarking and visual regression testing. It focuses on:
- **📸 Headless Rendering**: Comparing rendering speeds across different browser engine configurations.
- **🖼️ Visual snapshots**: Capturing and comparing screenshots to detect UI deviations.
- **📊 Performance metrics**: Tracking load times, CPU usage, and memory footprints during render cycles.

---

## 🛠️ Usage

Install dependencies:
```bash
npm install
```

Run render tests:
```bash
npm test
```
